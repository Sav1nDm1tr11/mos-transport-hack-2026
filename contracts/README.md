# contracts

Спецификации обмена между компонентами.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Источники: разделы 10 и 11 ТЗ. Потребители: packages/contracts, сервисы, frontend и тесты.

## Границы ответственности

Схемы пока не созданы. При реализации спецификации и исполняемые типы packages/contracts обновляются вместе; совместимость проверяется в tests/contract.

## Состав

- [events](events/README.md): Место для версионируемых схем Kafka и примеров событий.
- [http](http/README.md): Место для OpenAPI backend и примеров HTTP/SSE.
- [ml](ml/README.md): Документация границы с внешним ML API.

## Будущие проверки

Согласованность примеров, схем, типов и реализаций потребителей.
