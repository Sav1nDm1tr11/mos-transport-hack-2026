# contracts/http

Место для OpenAPI backend и примеров HTTP/SSE.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: разделы 11.1–11.2 ТЗ; выход при реализации: спецификация интерфейса backend для frontend.

## Границы ответственности

Не вводить новые endpoint или wire-формат в рамках каркаса. Исполняемые типы находятся в packages/contracts.

## Будущие проверки

Методы и ошибки, права зон, идемпотентность действий и восстановление SSE.
