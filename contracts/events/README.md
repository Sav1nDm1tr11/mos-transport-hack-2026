# contracts/events

Место для версионируемых схем Kafka и примеров событий.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: раздел 10.1 ТЗ; потребители: gateway, replay и worker.

## Границы ответственности

Названия топиков, идентификаторы и правила версий брать из ТЗ, не определять заново.

## Будущие проверки

Совместимость производителей и потребителей, неверная версия и повтор события.
