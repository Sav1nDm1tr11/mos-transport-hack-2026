Исходники и конфигурация появятся при реализации; этот каталог организует указанную область ответственности.

## Состав

- [consumption](consumption/README.md): Чтение Kafka, валидация событий, дедупликация и управление подтверждением обработки.
- [incidents](incidents/README.md): Оркестрация обновления ситуаций и проблем данных с использованием общих доменных правил.
- [ml_client](ml_client/README.md): HTTP-клиент внешнего ML API: сериализация, тайм-ауты и обработка ответов по согласованному контракту.
- [persistence](persistence/README.md): Согласованное сохранение результатов обработки через общий слой storage; обновление кеша и outbox.
- [prediction_orchestration](prediction_orchestration/README.md): Планирование batch-запросов, фиксация входного среза и применение ответов или резервного режима.
- [schedule_matching](schedule_matching/README.md): Сопоставление ТС с планом и выбор целевого посещения; оценки наблюдаемого отклонения.
- [vehicle_state](vehicle_state/README.md): Обновление состояния ТС, окон истории, качества и свежести телеметрии.
