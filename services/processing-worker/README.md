# services/processing-worker

Обработка телеметрии, состояния ТС, расписания, прогнозов и жизненного цикла ситуаций в одном процессе.

Статус на 26.09.2026: реализован локальный backend-профиль. Запуск и ограничения — `docs/development/backend.md` от корня репозитория. Ниже сохранены границы целевой полной системы; не все её возможности входят в локальную поставку.

## Входы, выходы и зависимости

Вход: Kafka, план и ответы внешнего ML API. Выход: долговременное состояние PostgreSQL, кеш Redis и изменения для UI. Зависимости: confluent-kafka, Pydantic, HTTPX и общие пакеты; Python 3.12.

## Границы ответственности

Общие правила ситуаций находятся в packages/domain. Worker не выполняет модельную предобработку и не заменяет пользовательские действия backend.

## Состав

- [src](src/README.md): Навигация по модулям src.
- [tests](tests/README.md): Будущие локальные проверки processing-worker.

## Будущие проверки

Дубли, поздние события, смена целевого посещения, устаревшие данные, недоступный ML и повторное чтение Kafka.
