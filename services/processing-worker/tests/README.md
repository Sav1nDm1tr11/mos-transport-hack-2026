# services/processing-worker/tests

Будущие локальные проверки processing-worker.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: изолированные примеры и тестовые зависимости; выход: результаты проверок сервиса.

## Границы ответственности

Межкомпонентные проверки находятся в корневом tests/integration; здесь проверяются обязанности одного сервиса.

## Будущие проверки

Дубли, поздние события, смена целевого посещения, устаревшие данные, недоступный ML и повторное чтение Kafka.
