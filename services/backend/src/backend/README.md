## Состав

- [actions](actions/README.md): Просмотр конкретной ревизии, личное наблюдение и обратная связь оператора.
- [api](api/README.md): HTTP-маршруты, связывание запросов с прикладными операциями и представление ошибок по разделу 11 ТЗ.
- [auth](auth/README.md): Идентификация пользователя, роли и серверная проверка доступных зон.
- [exports](exports/README.md): Формирование сводок и выгрузок доступного пользователю снимка.
- [queries](queries/README.md): Чтение обзора, очередей, карточек, истории, карты и проблем данных.
- [sse](sse/README.md): Доставка разрешённых изменений и восстановление подписки согласно разделу 11.2 ТЗ.
