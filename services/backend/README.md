# services/backend

API рабочего места оператора: доступ, чтение, действия, экспорт и SSE.

Статус на 26.09.2026: реализован локальный backend-профиль. Запуск и ограничения — `docs/development/backend.md` от корня репозитория. Ниже сохранены границы целевой полной системы; не все её возможности входят в локальную поставку.

## Входы, выходы и зависимости

Вход: запросы пользователя и состояние платформы. Выход: REST-ответы, выгрузки и поток обновлений. Зависимости: FastAPI, Pydantic, SQLAlchemy, PostgreSQL, Redis и общие пакеты.

## Границы ответственности

Сервер проверяет роли и зоны. API следует разделу 11 ТЗ. Backend не принимает NDTP и не рассчитывает собственную версию транспортного риска.

## Состав

- [src](src/README.md): Навигация по модулям src.
- [tests](tests/README.md): Будущие локальные проверки backend.

## Будущие проверки

Доступ к зонам, пагинация, повтор действий, конфликт ревизий, экспорт и переподключение SSE.
