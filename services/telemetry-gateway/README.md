# services/telemetry-gateway

Приём NDTP по TCP, разбор кадров и нормализация телеметрии.

Статус на 26.09.2026: реализован локальный backend-профиль. Запуск и ограничения — `docs/development/backend.md` от корня репозитория. Ниже сохранены границы целевой полной системы; не все её возможности входят в локальную поставку.

## Входы, выходы и зависимости

Вход: поток NDTP и привязки устройств. Выход: нормализованные события и диагностические ошибки Kafka. Зависимости: asyncio, confluent-kafka, общие контракты и конфигурация; Python 3.12.

## Границы ответственности

Не рассчитывает прогнозы и ситуации. Нормализованный поток соответствует разделам 6.1 и 10.1 ТЗ; протокол задаётся документацией датасета.

## Состав

- [src](src/README.md): Навигация по модулям src.
- [tests](tests/README.md): Будущие локальные проверки telemetry-gateway.

## Будущие проверки

Фрагментация TCP, несколько кадров за чтение, неверные пакеты, неизвестное устройство, повтор публикации и недоступность Kafka.
