# tools

Прикладные утилиты подготовки данных, демонстрации и администрирования.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: файлы, параметры администратора и конфигурация; выход: проверенные данные, события или аудируемые операции.

## Границы ответственности

Обучение, оценка модели и submission не входят. Скрипты обслуживания окружения находятся в scripts.

## Состав

- [admin](admin/README.md): Административные операции с доступом, зонами, настройками и запуском демонстрации.
- [csv-replay](csv-replay/README.md): Воспроизведение исторической телеметрии с управляемыми часами.
- [data-import](data-import/README.md): Импорт CSV, справочников, привязок устройств и расписаний с отчётом качества.

## Будущие проверки

Повторяемость операций, валидация и разделение демонстрационных запусков.
