# tools/admin

Административные операции с доступом, зонами, настройками и запуском демонстрации.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: команды администратора; выход: валидированные изменения и аудит. Зависит от storage и runtime.

## Границы ответственности

Начальные данные принадлежат infra/postgres/seeds; бизнес-импорт — data-import. Не создавать широкий admin API без отдельного решения.

## Будущие проверки

Повторяемость подготовки, права доступа и журналирование изменений.
