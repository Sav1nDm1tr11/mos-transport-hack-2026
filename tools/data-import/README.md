# tools/data-import

Импорт CSV, справочников, привязок устройств и расписаний с отчётом качества.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: dataset и настройки; выход: версии данных, план и связи в PostgreSQL через packages/storage.

## Границы ответственности

Не изменять исходные CSV; не выдавать фактическую разметку за плановые признаки. DDL находится в infra/postgres/migrations.

## Будущие проверки

Повторный импорт, пустые поля, временные зоны, геометрия и ошибочные связи.
