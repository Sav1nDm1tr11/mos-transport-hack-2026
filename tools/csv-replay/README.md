# tools/csv-replay

Воспроизведение исторической телеметрии с управляемыми часами.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: CSV, версия данных и параметры запуска; выход: события Kafka по общему контракту.

## Границы ответственности

Не заполняет UI или таблицы прогнозов в обход worker; учитывает доступность сведений на момент воспроизведения.

## Будущие проверки

Детерминированность событий, изоляция run_id и повторное воспроизведение.
