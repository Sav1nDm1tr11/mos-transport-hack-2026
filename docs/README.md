# docs

Навигация по требованиям, разработке и эксплуатации проекта.

Статус: локальный end-to-end профиль реализован; документы ниже разделяют работающий контур и целевую архитектуру.

## Входы, выходы и зависимости

Исходные решения описаны в архитектуре, ТЗ, CJM и дизайне; новые инструкции связываются с соответствующей подсистемой.

## Границы ответственности

Существующие документы и материалы superpowers сохраняются. ТЗ имеет статус проекта; эта структура не означает реализацию или приёмку требований.

## Состав

- [decisions](decisions/README.md): Архитектурные решения с контекстом, выбранным вариантом и последствиями.
- [development](development/README.md): Руководства для разработчиков, включая [ML-модели и production-routing](development/ml-models.md).
- [operations](operations/README.md): Будущие инструкции запуска, диагностики, резервного копирования и восстановления.

## Будущие проверки
