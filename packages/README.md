# packages

Общие библиотеки платформы с единым владельцем правил, типов, хранения и технических функций.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Используются gateway, worker, backend и инструментами в пределах их ответственности.

## Границы ответственности

Библиотеки не содержат точки запуска сервисов. Модельные признаки и библиотеки ML сюда не входят.

## Состав

- [contracts](contracts/README.md): Исполняемые типы и валидаторы согласованных контрактов.
- [domain](domain/README.md): Общие правила ситуаций, качества, состояний и ревизий внимания.
- [runtime](runtime/README.md): Общая конфигурация, JSON-логи, метрики и технический жизненный цикл.
- [storage](storage/README.md): Модели хранения, репозитории и адаптеры PostgreSQL/PostGIS и Redis.

## Будущие проверки

Совместимость потребителей и отсутствие независимых реализаций одних правил.
