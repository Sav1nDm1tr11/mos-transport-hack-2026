# packages/contracts/tests

Будущие локальные проверки библиотеки contracts.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: спецификации корневого contracts; выход: совместимые типы для сервисов и инструментов.

## Границы ответственности

Корневой contracts хранит спецификации обмена, этот пакет — их реализацию. Изменения синхронизируются и проверяются контрактными проверками; отдельная версия схем не допускается.

## Будущие проверки

Совместимость типов со схемами, обязательные поля, версии и ошибочные сообщения.
