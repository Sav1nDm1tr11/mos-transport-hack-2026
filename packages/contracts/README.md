# packages/contracts

Исполняемые типы и валидаторы согласованных контрактов.

Статус на 26.09.2026: реализован локальный backend-профиль. Запуск и ограничения — `docs/development/backend.md` от корня репозитория. Ниже сохранены границы целевой полной системы; не все её возможности входят в локальную поставку.

## Входы, выходы и зависимости

Вход: спецификации корневого contracts; выход: совместимые типы для сервисов и инструментов.

## Границы ответственности

Корневой contracts хранит спецификации обмена, этот пакет — их реализацию. Изменения синхронизируются и проверяются контрактными проверками; отдельная версия схем не допускается.

## Состав

- [src](src/README.md): Исходный код библиотеки contracts.
- [tests](tests/README.md): Будущие локальные проверки библиотеки contracts.

## Будущие проверки

Совместимость типов со схемами, обязательные поля, версии и ошибочные сообщения.
