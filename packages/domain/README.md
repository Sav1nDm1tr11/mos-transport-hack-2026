# packages/domain

Общие правила ситуаций, качества, состояний и ревизий внимания.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: доменные факты и настройки; выход: решения и переходы. Потребители: worker и backend.

## Границы ответственности

Не зависит от HTTP, Kafka и ORM; не содержит признаки модели.

## Состав

- [src](src/README.md): Исходный код библиотеки domain.
- [tests](tests/README.md): Будущие локальные проверки библиотеки domain.

## Будущие проверки

Жизненный цикл, смена цели, ухудшения и различение риска и качества данных.
