# packages/storage

Модели хранения, репозитории и адаптеры PostgreSQL/PostGIS и Redis.

Статус на 26.09.2026: реализован локальный backend-профиль. Запуск и ограничения — `docs/development/backend.md` от корня репозитория. Ниже сохранены границы целевой полной системы; не все её возможности входят в локальную поставку.

## Входы, выходы и зависимости

Вход: прикладные операции; выход: сохранённое или прочитанное состояние. Потребители: worker, backend и административные инструменты.

## Границы ответственности

DDL-миграции и начальные данные находятся в infra/postgres. Redis — восстанавливаемый кеш, не единственный источник истории.

## Состав

- [src](src/README.md): Исходный код библиотеки storage.
- [tests](tests/README.md): Будущие локальные проверки библиотеки storage.

## Будущие проверки

Транзакции, ограничения уникальности, восстановление кеша и пространственные выборки.
