# apps/frontend

Рабочее место оператора-аналитика по DESIGN.md.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: снимки REST и обновления SSE backend. Выход: отображение данных и запросы действий пользователя. Планируемый стек: React, TypeScript, Vite, MapLibre GL JS и Apache ECharts.

## Границы ответственности

Frontend не вычисляет задержку или правила риска и не обращается к ML напрямую. Экран входа и отказа в доступе относится к pages; обратная связь — к incident_details.

## Состав

- [public](public/README.md): Статические публичные ресурсы интерфейса.
- [src](src/README.md): Навигация по модулям src.
- [tests](tests/README.md): Будущие компонентные и локальные проверки frontend; сквозные сценарии находятся в корневом tests/e2e.

## Будущие проверки

Пустое состояние, загрузка, ошибка, устаревшие данные, потеря соединения, отсутствие прав и основные сценарии оператора.
