Навигация по модулям features.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Связи описаны в README соответствующей подсистемы и вложенных каталогах.

## Границы ответственности

Исходники и конфигурация появятся при реализации; этот каталог организует указанную область ответственности.

## Состав

- [attention_queue](attention_queue/README.md): Очередь внимания, фильтрация, сортировка и выбор ситуации.
- [data_quality](data_quality/README.md): Отдельное представление проблем телеметрии и свежести данных.
- [history](history/README.md): История ситуаций, посещений и изменений с фильтрами.
- [incident_details](incident_details/README.md): Карточка ситуации, прогноз, основания, качество, график и диалог обратной связи.
- [map](map/README.md): Карта, положение ТС, пространственная агрегация и связь с выбранной ситуацией.
- [overview](overview/README.md): Обзор смены, контекст зоны и времени, показатели текущего снимка.
- [summary](summary/README.md): Предпросмотр снимка сводки, копирование и скачивание экспорта.
- [watchlist](watchlist/README.md): Личные наблюдаемые ситуации и переходы к ним.
