# scripts

Команды обслуживания среды разработки и эксплуатации.

Статус: документированный каркас. Реализация и запуск пока отсутствуют.

## Входы, выходы и зависимости

Вход: параметры окружения; выход: подготовленная среда, резервная копия или восстановление.

## Границы ответственности

Прикладная логика импорта, replay и администрирования находится в tools; работающих shell-скриптов пока нет.

## Состав

- [backup](backup/README.md): Будущие команды резервного копирования долговременного состояния и метаданных.
- [dev](dev/README.md): Будущие вспомогательные команды разработки и проверок окружения.
- [restore](restore/README.md): Будущие команды восстановления из резервных копий.

## Будущие проверки

Явные параметры, диагностируемые ошибки и сохранность данных.
