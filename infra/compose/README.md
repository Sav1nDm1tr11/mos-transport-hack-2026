# infra/compose

Совместный запуск платформы и профили replay, NDTP-эмулятора и наблюдаемости; внешнее подключение ML.

Статус на 26.09.2026: реализован локальный backend-профиль. Запуск и ограничения — `docs/development/backend.md` от корня репозитория. Ниже сохранены границы целевой полной системы; не все её возможности входят в локальную поставку.

## Входы, выходы и зависимости

Входы, выходы и зависимости определяются контрактами родительской подсистемы; конкретные типы появятся при реализации.

## Границы ответственности

Размещать здесь только материалы указанной ответственности. Общие правила и контракты подключать из общих пакетов.

## Будущие проверки

Зависимости по health-check, конфигурация профилей и сохранность данных после перезапуска.
